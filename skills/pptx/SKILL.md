# PPTX Generation Rules

- Use `pptxgenjs` and keep each slide focused on one message.
- Use consistent margins, readable type, and explicit layouts rather than relying on automatic placement.
- Prefer concise titles, short supporting text, and visual hierarchy over dense paragraphs.
- Validate that the presentation is structurally readable before saving the final file to /sandbox/outputs.
